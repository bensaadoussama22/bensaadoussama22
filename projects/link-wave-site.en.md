# link-wave-site

Web management application designed for field teams (technicians, maintenance, on-site interventions). The source code of this project remains private — this page presents the project without exposing the code.

## 🎯 Goal

Provide companies with a centralized tool to track technical interventions: from a fault being reported by a client or agent, all the way to its resolution by a technician on-site.

## ✨ Key Features

- **Fault reporting** — quick incident declaration with description and priority.
- **Technician tracking** — assignment of interventions and real-time on-site location.
- **Notifications** — automatic alerts to technicians and managers on ticket updates.
- **Management dashboard** — overview of ongoing, completed, and pending interventions.
